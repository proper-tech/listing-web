# ProperTech — үл хөдлөх хөрөнгийн зарын сайт (прототип)

`real-estate-platform-plan.md`-ийн дагуу хийсэн ажиллах прототип: Phase 1 бүхэлдээ, Phase 2-оос 360° хэсэг.

- **Frontend:** Next.js 16 (App Router) + React 19 + TypeScript
- **Backend:** [`listing-server`](../listing-server) API — нэвтрэлт ([`lib/api/auth.ts`](lib/api/auth.ts)), зар, зураг ([`lib/api/listings.ts`](lib/api/listings.ts)). Админ самбарын агент удирдлага, зарын гомдол одоохондоо **mock** ([`lib/mock/`](lib/mock)).

## Ажиллуулах

Node.js 20+ хэрэгтэй.

```bash
npm install
npm run dev
```

http://localhost:3000 нээнэ. Нэвтрэхийн тулд `listing-server`-ийг (`npm run dev`, порт 4000) асааж, `.env`-д `API_URL=http://localhost:4000` тавина.
`/api/*` хүсэлтийг `next.config.ts` API_URL руу дамжуулна (`.env` өөрчилсний дараа dev серверээ дахин асаана).

## Mock өгөгдөл

- [`lib/mock/seed.ts`](lib/mock/seed.ts) — 2 хэрэглэгч (админ агент удирдлагад). Жишээ зар байхгүй: зарууд `listing-server` API-аас ирнэ. [`public/mock/demo-capture/`](public/mock/demo-capture) — PostWizard-ийн туршилтын 12 зураг.
- [`lib/mock/api.ts`](lib/mock/api.ts) — хайлт, зар нэмэх, админ гэх мэт "API"-г хөтөч дотор гүйцэтгэнэ. Нэвтэрсэн агентыг `mirrorSession()` mock DB-д тусгана (имэйлээр тааруулна).
  Өөрчлөлт (шинэ зар, агент, нууц үг...) хөтчийн IndexedDB-д хадгалагдана; тухайн хөтөч дээр л харагдана.
- Оруулсан зураг data: URL болж зартайгаа хадгалагдана.
- Анхны төлөвт буцаах: Админ самбар → "Mock өгөгдөл шинэчлэх" (эсвэл хөтчийн site data-г цэвэрлэх).

## Нэвтрэлт (зөвхөн админ, агент)

Зар үзэхэд нэвтрэх шаардлагагүй. **Зар нэмэх, Миний зар, Админ** хуудсууд зөвхөн нэвтэрсэн хэрэглэгчид.
Нийтийн бүртгэл байхгүй — агентын эрхийг **админ** Админ самбар → "Агентууд" хэсэгт үүсгэнэ.

Бүх хэрэглэгч **имэйл хаяг** (Gmail эсвэл өөр ямар ч имэйл) + нууц үгээр нэвтэрнэ.

| Эрх | Юу хийж чадах |
|---|---|
| Админ | Бүх зар батлах/нуух/устгах; агент нэмэх (нэр, имэйл, утас, түр нууц үг), имэйл солих, идэвхгүй болгох, нууц үг шинэчлэх. Өөрийн зар шууд нийтлэгдэнэ |
| Агент | Зар нэмэх (админ баталсны дараа нийтлэгдэнэ), өөрийн зарыг удирдах. Утасны дугаар нь зөвхөн зар дээрх холбоо барих дугаар |

Нэвтрэлт `listing-server`-ийн `/api/auth/*` (login, logout, me, change-password)-аар явна. Сешн нь HttpOnly JWT cookie.
Агент үүсгэх: `listing-server` дотор `npm run agent:create -- <email> "<нэр>" [admin|agent] --local` (түр нууц үг хэвлэнэ).

Анх нэвтрэхдээ түр нууц үгээ заавал солино. Админ самбарын агент удирдлага одоохондоо mock (тэнд үүсгэсэн агент нэвтэрч чадахгүй).

## Бүтэц

```
app/                  Next.js хуудсууд
  page.tsx            Нүүр
  search/             Хайлт, шүүлтүүр
  listing/[id]/       Зарын хуудас
  post/               Зар нэмэх 7 алхам (нэвтрэх шаардлагатай)
  login/ account/     Нэвтрэх, нууц үг солих
  saved/ my/ admin/   Хадгалсан + харьцуулах, Миний зар, Админ (+ агент удирдах)
  help/ pricing/      Статик хуудас
components/           React компонентууд (TourViewer, Maps, PostWizard, ...)
lib/                  Төрлүүд, тогтмолууд, localStorage, 360° холбогч (stitch.js)
  mock/               Mock өгөгдөл + mock API (IndexedDB)
public/mock/          PostWizard-ийн туршилтын зурагнууд (demo-capture)
```

- **360° viewer:** Pannellum (CDN-ээс), **газрын зураг:** Leaflet + OpenStreetMap
- **360° холбох (Mode B):** `lib/stitch.js` — хөтөч дээр ажиллана (цилиндр проекц → NCC → тойрог хаах → equirectangular)
